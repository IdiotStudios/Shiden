# Shiden Documentation Examples

- **Types**: All primitive types (u8-u64, i8-i64, f32, f64, str, char, bool, array, unit)
- **Variables**: Immutable and mutable bindings, assignments, index assignments
- **Expressions**: Arithmetic, comparison, logical operators, precedence, grouping, unary ops
- **Control Flow**: if/else, while loops, for loops, break, continue, return
- **Functions**: Simple functions, parameters, return types
- **Arrays**: Array literals, indexing, dynamic arrays with push

Run With

```bash
cargo run -- run examples/docs/
```

Or compile and run directly:

```bash
cargo run -- compile examples/docs/
./examples/docs/build/x86_64-linux/docs_demo
```
