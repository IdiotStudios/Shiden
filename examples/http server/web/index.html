Welcome to Shiden

This page is served by a web server written in Shiden, a custom programming language that compiles directly to x86_64 machine code.

Technical Features

  • Raw TCP sockets - socket(41), bind(49), listen(50), accept(43)
  • HTTP/1.1 protocol - Full request parsing and response generation
  • Static file serving - HTML, CSS, and JavaScript
  • Zero dependencies - Compiles to standalone ELF binary
  • Direct syscalls - write(1), read(0), close(3)

How It Works

fn new main/
    let server = net server new(8000)/i64
    
    while true/
        let client = net server accept(server)/i64
        let path = parse request(net recv(client)/i64)/str
        let content = fs read(path)/str
        
        net send(client, build response(content))/i64
        net close(client)/i64
    while/
fn/
