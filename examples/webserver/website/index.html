Welcome to Shiden

A pure compiled language with zero runtime overhead

Lightning Fast

This web server is written entirely in Shiden and compiles to native machine code. No interpreters, no virtual machines, no garbage collectors. Just pure x86_64 binaries.

System-Level Programming

Direct access to system calls. This server uses Linux syscalls (socket, bind, listen, accept, send, close) embedded as bytecode in the compiled binary.

No Dependencies

No Rust runtime • No Python • No Node.js • No external libraries

Just a small native executable serving this entire website.
